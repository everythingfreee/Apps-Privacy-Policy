MediaRescue Privacy Policy

Your media and files stay on your device. MediaRescue is designed as an offline-first Android application for finding, browsing, previewing, and managing media and files.

Effective date: September 29, 2026 ```
```

1. Introduction

This Privacy Policy explains how MediaRescue handles information when you use the application.

MediaRescue is an offline-first application designed to process your files locally on your Android device. The application does not require an account for its core functionality.

Privacy at a glance
Your personal files and media are processed locally. MediaRescue does not upload your personal files, media, thumbnails, or file paths to MediaRescue's cloud services. A small amount of anonymous installation and diagnostic information is optionally synchronized to Firebase Cloud Firestore to help us understand app usage, compatibility, and activity.

2. Information MediaRescue Accesses

MediaRescue requires access to storage so it can find, display, preview, search, and manage files stored on your device.

Files and Media

Depending on your Android version and the permissions you grant, MediaRescue can access files and media stored on accessible device storage.

This can include:

  • Images
  • Videos
  • Audio files
  • PDF documents
  • Other accessible files

MediaRescue uses this access for features such as storage scanning, file searching, gallery views, previews, browsing, large-file identification, hidden-media discovery, and advanced scanning.

3. How Your Files Are Processed

MediaRescue processes accessible files locally on your Android device.

Your files are not uploaded to MediaRescue cloud services for scanning, searching, previewing, playback, or file management.

✓ Local processing File scanning, media discovery, previews, and file management are performed on your device.
✓ Offline-first Core MediaRescue functionality does not require an internet connection.
✓ No account required You do not need to create an account to use the core features of MediaRescue.
✓ No personal file uploads MediaRescue does not upload your personal files, media, thumbnails, or file paths to its cloud services.

4. Anonymous Installation & Activity Diagnostics

Starting with MediaRescue v1.0.9, the application uses Firebase Cloud Firestore for limited, anonymous installation and activity diagnostics.

This information helps us understand how many installations are using MediaRescue, which app versions and Android versions are in use, and whether compatibility issues may affect particular device models or software versions.

Information Used for Diagnostics

Depending on the available information on your device, MediaRescue may synchronize the following diagnostic data:

  • A randomly generated installation ID
  • Firebase Cloud Messaging (FCM) token
  • Last recorded app activity
  • MediaRescue app version
  • Android version
  • Device model

The installation ID is randomly generated for the installation and is not your name, email address, phone number, or other directly identifying information.

What We Do Not Send

Diagnostic synchronization does not include:

  • Your name or email address
  • Your contacts
  • Your location
  • Your photos, videos, or audio files
  • Your personal documents
  • Your media thumbnails
  • Your file paths
  • The contents of your files

Offline-First Synchronization

Diagnostic information is cached locally and is not required to be transmitted immediately. When network connectivity is available, the application can synchronize diagnostic information approximately once every 24 hours.

If you use MediaRescue while offline, diagnostic information can remain locally cached and may be synchronized later when connectivity becomes available.

Why is this collected?
The purpose is limited to understanding installation counts, app activity, software-version compatibility, device-specific issues, and release adoption. It is not used to upload or analyze the contents of your files.

5. Firebase Cloud Firestore

MediaRescue uses Firebase Cloud Firestore as the backend service for anonymous installation and diagnostic data described in Section 4.

Firestore is operated by Google and is a third-party infrastructure service used to store the limited diagnostic information described in this policy.

MediaRescue does not use Firestore to store your personal media, documents, file contents, media thumbnails, or file paths.

The use of Firebase is limited to the diagnostic and notification-related functionality described in this Privacy Policy.

6. Local Memories & Anniversary Notifications

MediaRescue v1.0.9 includes a local Memories feature that can remind you about images, videos, and audio files associated with dates from previous years.

Memory information is stored locally on your device. This can include information such as:

  • Local file path
  • Media type
  • Creation or relevant media date
  • Locally cached artwork or thumbnail data
  • Notification bookkeeping information

This Memory metadata is used to create local anniversary notifications and reopen the corresponding media when you interact with a notification.

Memory data stays local.
MediaRescue does not upload Memory metadata, file paths, thumbnails, or the associated media to Firebase or a MediaRescue cloud server.

Memory notifications use Android's local notification system and can operate without an internet connection.

7. Notification Permissions and FCM

MediaRescue may use Android notifications for features such as Memory reminders, playback controls, and other application functionality.

Depending on your Android version and notification settings, you can control whether MediaRescue is allowed to display notifications.

MediaRescue may store an FCM token as part of its anonymous diagnostic information. This token can allow the application infrastructure to identify an installation for future notification-related functionality.

The FCM token does not contain your personal files or the contents of your media.

8. Advanced Scan Preview Cache

MediaRescue may create a local preview cache for thumbnails and previews generated during Advanced Scan.

The cache is stored on your device and is protected from normal Android media indexing using a .nomedia marker.

This prevents cached preview files from unnecessarily appearing as normal media in other gallery or media applications.

The preview cache is local to your device and is not uploaded to MediaRescue cloud services.

9. Information We Do Not Intentionally Collect

MediaRescue does not intentionally collect personal information such as:

  • Your name
  • Your email address
  • Your phone number
  • Your contacts
  • Your precise location
  • Your photos, videos, or audio on a remote server
  • Your personal documents
  • The contents of your files

MediaRescue also does not require user registration or a personal account for its core functionality.

Please note that anonymous diagnostic identifiers, such as a randomly generated installation ID or an FCM token, may still be used as described in this policy.

10. Internet Access

MediaRescue is designed to provide its core functionality without requiring an internet connection.

Internet connectivity may be used for limited functionality such as synchronizing anonymous diagnostics with Firebase Cloud Firestore.

MediaRescue does not use your internet connection to upload your personal files, media, thumbnails, or file contents to MediaRescue cloud services.

11. Third-Party Services

MediaRescue uses limited third-party infrastructure for specific functionality.

Firebase Cloud Firestore

Firebase Cloud Firestore is used to store the anonymous installation and diagnostic information described in this Privacy Policy.

Firebase services are provided by Google. Google's handling of information is governed by Google's applicable privacy policies and service terms.

MediaRescue does not use third-party advertising networks to display advertisements inside the application.

MediaRescue is also distributed through third-party platforms such as Google Play, F-Droid, APKPure, Softonic, Uptodown, GitHub, and other distribution services. These platforms may have their own privacy policies and data practices that apply when you use their services.

12. Storage Permissions

Storage access is required because MediaRescue's primary purpose involves finding and managing files on your device.

You remain in control of granting or denying storage access through Android's permission and access systems.

If you deny required access, some MediaRescue features, such as scanning and browsing device storage, may not function.

MediaRescue may also use Android's supported access mechanisms for advanced storage locations when you explicitly enable and authorize those features.

13. Data Security

MediaRescue is designed to reduce privacy risks by processing personal files locally instead of sending them to remote servers.

Anonymous diagnostic information synchronized with Firebase is limited to the information described in this Privacy Policy.

You should still protect your Android device using appropriate device security measures such as a screen lock and current system security updates.

14. Data Retention

Local file information, Memory metadata, previews, thumbnails, and other application data may remain on your device until they are removed by MediaRescue, Android, or you.

Anonymous diagnostic information synchronized with Firebase may remain available for operational and compatibility analysis for as long as reasonably necessary for those purposes.

Uninstalling MediaRescue removes the application's local data according to Android's normal application data handling. This does not necessarily remove previously synchronized anonymous diagnostic records from Firebase.

15. Children's Privacy

MediaRescue does not intentionally collect names, contact information, or other directly identifying personal information from children.

The application does not require an account for its core functionality. The limited anonymous diagnostic information described in this policy may still be processed when the application is used.

This Privacy Policy may be updated when MediaRescue introduces new functionality, changes how information is handled, or when legal or platform requirements change.

The effective date at the top of this page indicates when the current version of this Privacy Policy became effective.

18. Contact

If you have questions, concerns, or suggestions regarding this Privacy Policy or MediaRescue's privacy practices, please contact the developer through the project's GitHub repository.

Contact / Report an Issue →

19. Summary

MediaRescue is built with a privacy-first approach.

Your personal files and media are processed locally on your device. MediaRescue does not require an account and does not upload your files, media, thumbnails, file paths, or file contents to its cloud services.

MediaRescue v1.0.9 does use Firebase Cloud Firestore for limited anonymous installation and activity diagnostics, such as a randomly generated installation ID, app version, Android version, device model, last activity, and an FCM token. This information is synchronized approximately once every 24 hours when connectivity is available.

Memory metadata and preview-cache information remain stored locally on your device and are not uploaded as part of this diagnostic system.
